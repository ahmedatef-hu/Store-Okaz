# ستور عكاظ - Store Okaz

![Store Okaz](public/assets/Okaz-logo.png)

## 🌟 عن المشروع

موقع إلكتروني فاخر لمتجر البخور والعطور الشرقية والإكسسوارات الفاخرة في البحرين.

تم تحويله من HTML/CSS/JS إلى **React + Vite + Tailwind CSS** مع الحفاظ على نفس التصميم بالكامل.

## ✨ المميزات

- ⚡ **React + Vite** - أداء سريع وتجربة تطوير رائعة
- 🎨 **Tailwind CSS** - تصميم عصري وسهل التخصيص
- 📱 **Responsive Design** - يعمل على جميع الأجهزة
- 🌐 **RTL Support** - دعم كامل للغة العربية
- 🎭 **Animations** - أنيميشنز سلسة وجذابة
- 🛒 **Shopping Features** - نظام سلة تسوق وإشعارات
- 📞 **WhatsApp Integration** - تواصل مباشر عبر واتساب
- 🎵 **TikTok Integration** - ربط مباشر بالتيك توك

## 🚀 البدء

### المتطلبات

- Node.js 18+ 
- npm أو yarn

### التثبيت

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/okaz-store-react.git

# Navigate to project directory
cd okaz-store-react

# Install dependencies
npm install

# Start development server
npm run dev
```

الموقع سيعمل على: `http://localhost:5173/`

### Build للإنتاج

```bash
npm run build
```

### Preview البناء

```bash
npm run preview
```
